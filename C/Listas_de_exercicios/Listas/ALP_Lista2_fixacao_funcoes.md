# Exercícios de Fixação — Funções em C

Lista mais avançada sobre funções: retorno de valores, passagem de vetores e matrizes como parâmetro, funções auxiliares chamando outras funções e correção de erros de escopo/retorno.

## Exercícios

1. Questão de múltipla escolha sobre o retorno de uma função `bool aprovado(...)`.
2. Implementar `calcularValor` (preço por hora × horas de aluguel de bicicleta).
3. Analisar por que uma função `void aumentarNivel(int nivel)` não altera a variável do `main` (passagem por valor) e fazer teste de mesa.
4. Completar uma função que conta quantos valores de um vetor são maiores que um limite.
5. Implementar `taxaEntrega(codigo)` retornando a taxa conforme o código do tipo de envio (ou -1 se inválido).
6. Corrigir uma função `void podeSair(...)` que tenta usar `return 1`/`return 0` incorretamente (deveria retornar `int`).
7. Implementar `atingiuMeta` usando o operador ternário para verificar se uma meta de passos foi atingida.
8. Implementar `somaAmostra` que soma os valores de uma linha de uma matriz 4×3 de populações de bactérias.
9. Implementar `mediaTemperaturas` e `diasAcimaDaMedia` para um vetor de 7 temperaturas.
10. Implementar `mediaAvaliacoes` ignorando valores `-1` (avaliações canceladas).
11. Implementar `contarVogais` em uma string, considerando maiúsculas e minúsculas.
12. Corrigir uma função `maiorValor` que falha com vetores contendo apenas números negativos (inicialização incorreta do "maior").
13. Implementar `gerarPontuacoes` (com `rand()`) e `maiorPontuacao` para simular arremessos de um atleta.
14. Corrigir uma função de cálculo de preço de ingresso que não possui `return`.
15. Implementar `consumoTotal` e `indiceMaiorConsumo` para um vetor de consumo de máquinas.
16. Implementar `calcularPontuacaoFinal` aplicando bônus percentual conforme a dificuldade de cada fase de um jogo.
17. Implementar `totalFilial` e `totalSemana` para uma matriz de vendas 3×4.
18. Implementar `senhaValida`, verificando tamanho mínimo, presença de maiúscula e de número.
19. Implementar `pontuacaoEtapa`, `calcularTotal` e `etapasCriticas` para uma competição de drones com bônus por condição climática.

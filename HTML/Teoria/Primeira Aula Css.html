O que é CSS?

CSS é a linguagem utilizada para definir a aparência e a apresentação de uma página HTML.

HTML define a estrutura. CSS define a aparência.

Seletores CSS

Podemos utilizar diferentes seletores para escolher quais elementos serão estilizados.

  • Seletor por TAG
  • Seletor por CLASS
  • Seletor por ID

# Estudos de Programação — PUC Campinas
 
Repositório com exercícios, listas e projetos desenvolvidos durante a graduação em Engenharia de Software na PUC-Campinas, na disciplina de Algoritmos e Linguagem de Programação e em outras matérias de programação.
 
## Objetivo
 
Servir como material de estudo e consulta, reunindo o código resolvido de cada lista de exercícios, organizado por linguagem e por tópico.
 
## Estrutura
 
```
C/
├── Listas_de_exercicios/   → listas resolvidas, organizadas por tópico (decisão, repetição, vetores, matrizes, ponteiros, funções, structs, revisões de prova)
└── Projetos/               → projetos maiores (sistema de controle de estoque, jogo da forca, etc.)
 
Python/       → scripts e exercícios em Python
JavaScript/   → scripts e exercícios em JavaScript
HTML/         → páginas de estudo/front-end
CSS/          → estilos de estudo/front-end
```
 
Cada subpasta de lista de exercícios contém um `README.md` com um resumo dos enunciados e o(s) arquivo(s) `.c` com a resolução.
 
## Como usar
 
- Navegue até a pasta da linguagem/tópico de interesse.
- O `README.md` de cada lista explica o que cada exercício pede.
- O código-fonte correspondente está no mesmo diretório.
## Sobre
 
Repositório de uso pessoal para fins de estudo e portfólio. Os enunciados das listas foram fornecidos pela disciplina (PUC-Campinas — Algoritmos e Linguagem de Programação); os resumos em cada README foram reescritos e não reproduzem os PDFs originais na íntegra.
